# D2NZ visual direction

Source identity: KingD2NZ/D2NZ-WBSITE. Carry across the white D2NZ wordmark, restrained red interaction accents and website typography where font redistribution permits it. Never colour the 2 red. Do not copy website application code into the DSP project.

Plugin surfaces: readable medium gunmetal/graphite, white type, subtle metallic texture. Avoid excessive glow, deep darkness, portraits and decorative AI visuals. Native JUCE rendering keeps the UI separate from web dependencies.

Easy view: header, text-only preset list, seven active macros until pitch exists, contextual analysis area and actual DSP meters. Details belong in hover/focus/click panels. Full metallic reference artwork has not yet been supplied; final dimensions, fonts and asset provenance require review before incorporation.

The current editor is a temporary functional parameter editor, not the final visual design. Website image/font assets have not been copied or redistributed. No cosmetic control should be displayed as working until backed by DSP.
